# Contributing

1. Fork the repository.
2. Create a branch from `main`.
3. Keep changes focused and document user-visible behavior.
4. Run `./scripts/build.ps1` on Windows before opening a pull request.
5. Do not commit Spotify files, copyrighted lyrics, credentials, tokens, generated `bin/obj`, or packaged third-party binaries.
6. Update `CHANGELOG.md` for user-visible changes.

For bugs, attach the output of `scripts/diagnose.ps1` after removing any personal path you do not want to share.
