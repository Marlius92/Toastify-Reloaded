### macOS — Preview 1

Toastify Reloaded for macOS is on the fast-track toward stable with a feature-complete first preview.

Current macOS preview tag:

```text
v1.5.0-macos-preview.1
```

Packages:

**Apple Silicon (arm64)**

- `ToastifyReloaded-macOS-arm64.dmg`
- `ToastifyReloaded-macOS-arm64.zip`

**Intel (x64)**

- `ToastifyReloaded-macOS-x64.dmg`
- `ToastifyReloaded-macOS-x64.zip`

The macOS port keeps the same Toastify Reloaded settings and desktop feature set while using native macOS platform adapters for Spotify control, global hotkeys, autostart, packaging and updates.

> macOS requires Automation permission for Spotify control and Accessibility permission for global hotkeys.
